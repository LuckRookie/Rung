# Inspect Card

Read when relevant project facts, rules, code, contracts, commands, dependencies, or user work are missing from the judgment.

## Operate

- Establish root, instructions, revision, working tree, user-owned edits, and tool entry points.
- Inspect the owner, callers, dependencies, tests, contracts, configuration and design facts needed next.
- For a bug, trace the failure to its rule or state owner and relevant sibling paths. Read [Engineering Structure](engineering-structure.md) when the cause crosses or exposes a faulty boundary.
- Expand to consumers, migrations, generation, build and release controls when impact requires it.
- Declare the boundary for a system-level audit. For project meaning, semantic center, feature fit, or intended evolution, read [Project Model](project-model.md).

Stop when owner, constraints, user work, impact and checks are bounded. Output sourced facts, commands, protected changes and unknowns.

Optional index: `python <rung-skill-root>/scripts/inspect_project.py --project <path> --output <context.json>`. Persist for coordination or recovery. See [Execution Model](execution-model.md) for inspection radius and [Project Harness](project-harness.md) for source conflicts.
