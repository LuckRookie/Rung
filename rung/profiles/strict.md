# Strict Profile

适用于新项目、核心架构、公共接口、安全隐私、持久化数据、跨模块依赖、大规模重构或发布链路变化。

## 最低责任

- 正式记录需求、验收条件和关键用户决策；
- 完成架构、接口、数据流、错误处理和威胁相关设计；
- 为具有长期影响的决定创建或更新 ADR；
- 明确兼容窗口、迁移顺序、回退条件和数据恢复路径；
- 持久化完整 Change Plan 和 Verification Plan；
- 执行 Tier 2–3 的集成、端到端、构建、打包和相关安全检查；
- 对范围、架构、兼容、安全、文档和 Release 做完整审查；
- 生成可复现 Release Package，并记录 revision、校验信息、已知限制和残余风险。

被用户接受的残余风险使用 `waived`，同时记录范围、理由、批准者和后续处理位置。
